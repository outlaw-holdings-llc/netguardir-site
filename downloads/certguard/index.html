3 · Launch + activate

  1. Run the unzipped binary. Windows: double-click; UAC self-elevates. macOS: xattr -d com.apple.quarantine certguard-0.1-macos-arm64 if Gatekeeper objects. Linux: chmod +x certguard-0.1-linux-x86_64 then run.
  2. 30-day trial starts automatically from first launch — all features unlocked, no activation needed to evaluate.
  3. Activate for ongoing use: CertGuard → Admin → Licensing → paste your activation key. Online activation needs one outbound HTTPS reach to licensing.netguardir.com; the license caches locally and works fully offline thereafter. SCIF / air-gapped installs can use the offline file-drop path instead.
  4. Same key, all platforms. The activation key gates both this .zip download and the in-app license activation — so you can re-download on a new machine or after losing the file, no portal account.
